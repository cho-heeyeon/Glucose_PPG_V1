# Glucose_PPG_V1

## 목적
스마트폰 후면 카메라/플래시를 이용해 검지에서 30초 RGB 광신호를 수집하고,
같은 시점의 **실제 혈당계 또는 CGM 기준값**을 함께 CSV로 저장하는 연구용 데이터 수집기입니다.

## 중요
- 이 V1은 혈당을 측정하거나 추정하지 않습니다.
- 화면에 임의의 혈당값을 생성하지 않습니다.
- 의료 진단, 투약, 인슐린 용량 결정에 사용하지 마세요.
- 연구용 모델을 만들려면 별도의 기준 혈당값과 충분한 검증 데이터가 필요합니다.

## 사용
1. HTTPS로 이 폴더를 웹 서버에 올립니다. (카메라 API는 일반적으로 HTTPS 필요)
2. 휴대폰 브라우저에서 index.html을 엽니다.
3. 카메라 권한을 허용합니다.
4. 검지 끝으로 후면 카메라/플래시 영역을 덮습니다.
5. 30초 측정합니다.
6. 가능한 한 같은 시점의 실제 혈당계/CGM 값을 입력합니다.
7. CSV를 저장합니다.

## 저장 데이터
sample_id, t_ms, red_mean, green_mean, blue_mean, reference_glucose_mg_dl

## 다음 단계
여러 측정 데이터를 확보한 뒤 Python에서 신호 품질 검사, 전처리, 특징 추출,
train/test 분리 및 회귀 모델의 MAE/RMSE 등을 평가합니다.
단, PPG만으로 임상적으로 신뢰할 수 있는 혈당 추정이 가능하다고 전제하지 않습니다.
